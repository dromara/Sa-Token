### 正式版本 
v1.46.0 正式版，可上生产：

``` xml
<!-- Sa-Token 权限认证 -->
<dependency>
    <groupId>cn.dev33</groupId>
    <artifactId>sa-token-spring-boot-starter</artifactId>
    <version>1.46.0</version>
</dependency>
```

Maven依赖一直无法加载成功？[参考解决方案](https://sa-token.com/start/maven-pull.html)
